# 2bit CPU 命令セット仕様書（ISA）

本ドキュメントは  
**2bit CPU 組み立てキット**  
https://naoto64.github.io/2bit-CPU/  
に基づく命令セット仕様（ISA: Instruction Set Architecture）をまとめたものです。

## 1. 基本仕様

### データ幅

- レジスタ幅：2bit
- 即値／アドレス幅：2bit
- 命令長：4bit（1 命令）

---

## 2. レジスタ構成

| レジスタ | 幅   | 説明               |
| -------- | ---- | ------------------ |
| A        | 2bit | 汎用レジスタ       |
| PC       | 2bit | プログラムカウンタ |
| C        | 1bit | キャリーフラグ     |

---

## 3. メモリ構成

- ROM 容量：16bit（4bit × 4 命令）
- アドレス空間：2bit（0〜3）

---

## 4. 命令フォーマット

```
[ OPCODE (2bit) ][ OPERAND (2bit) ]
   D3 D2           D1 D0
```

---

## 5. 命令一覧

### 5.1 ADD — 加算命令

| 項目         | 内容   |
| ------------ | ------ |
| ニーモニック | ADD Im |
| 機械語       | 00 Im  |

**動作**

```
{C, A} ← A + Im
```

---

### 5.2 IN — 入力命令

| 項目         | 内容  |
| ------------ | ----- |
| ニーモニック | IN A  |
| 機械語       | 01 xx |

**動作**

```
A ← INPUT
C ← 0
```

---

### 5.3 OUT — 出力命令

| 項目         | 内容   |
| ------------ | ------ |
| ニーモニック | OUT Im |
| 機械語       | 10 Im  |

**動作**

```
OUTPUT ← Im
C ← 0
```

---

### 5.4 JNC — 条件付きジャンプ命令

| 項目         | 内容     |
| ------------ | -------- |
| ニーモニック | JNC Addr |
| 機械語       | 11 Addr  |

**動作**

```
if C == 0:
    PC ← Addr
else:
    PC ← PC + 1
C ← 0
```

---

## 6. 入出力（I/O）仕様

### 6.1 入力ポート（INPUT）

- 幅：2bit
- 値域：0〜3
- CPU 外部に存在する入力端子
- `IN` 命令により値が A レジスタに読み込まれる
- 入力値は命令実行時点の端子状態を取得する

### 6.2 出力ポート（OUTPUT）

- 幅：2bit
- 値域：0〜3
- CPU 外部に存在する出力端子
- `OUT` 命令により即値が出力される
- 出力値は次の `OUT` 命令が実行されるまで保持される（出力ラッチ）

---

## 7. キャリーフラグ仕様

| 命令 | C の状態                               |
| ---- | -------------------------------------- |
| ADD  | 桁あふれが発生した場合 1、それ以外は 0 |
| IN   | 0                                      |
| OUT  | 0                                      |
| JNC  | 実行後に必ず 0                         |
