# 画面レイアウト設計

## 全体構成

```
┌─────────────────────────────────────────────────────────────┐
│  2bit CPU エミュレーター                                     │
├─────────────────────────────────────────────────────────────┤
│                                                               │
│  ┌─────────────────┐  ┌──────────────┐  ┌──────────────┐   │
│  │  CPU状態表示     │  │  ROM/メモリ   │  │  入力/出力   │   │
│  │  ┌───────────┐  │  │  ┌────────┐  │  │  ┌───────┐  │   │
│  │  │ A: [■][■]│  │  │  │命令表示 │  │  │  │ LED   │  │   │
│  │  │ PC:[■][■]│  │  │  │[0]...  │  │  │  │[■][■] │  │   │
│  │  │ C: [■]   │  │  │  │[1]...  │  │  │  └───────┘  │   │
│  │  │ cycles:0 │  │  │  │[2]...  │  │  │             │   │
│  │  └───────────┘  │  │  │[3]...  │  │  │  入力値:    │   │
│  │                 │  │  └────────┘  │  │  [■][■]     │   │
│  └─────────────────┘  └──────────────┘  └──────────────┘   │
│                                                               │
│  ┌───────────────────────────────────────────────────────┐  │
│  │  操作ボタン                                             │  │
│  │  [ ▶ 実行 ]  [ ⏸ 停止 ]  [ ⟲ リセット ]  [ 読込 ]  [ 保存 ]│
│  └───────────────────────────────────────────────────────┘  │
│                                                               │
│  ┌───────────────────────────────────────────────────────┐  │
│  │  実行ログ                                               │  │
│  │  [CYCLE 0] PC=0, 命令=00 (ADD Im=00), A: 00→00, C:0 │  │

│                                                               │
└─────────────────────────────────────────────────────────────┘
```

## 各パネルの詳細仕様

### 1. CPU 状態表示パネル（左上）

**位置・サイズ**

- 左上に配置
- 幅：約 250px、高さ：約 150px

**表示内容**

- **A レジスタ**：2bit を視覚的に表示（チェックボックス状または LED 状）
- **PC（プログラムカウンタ）**：現在値を 2 進数・10 進数で表示
- **C フラグ（キャリーフラグ）**：1bit の状態を表示
- **サイクル数**：現在までの実行サイクル数をカウント表示

**更新タイミング**

- CPU 命令実行後に即座に更新
- リセット時に初期化（A=00, PC=00, C=0, cycles=0）

### 2. ROM/メモリ表示パネル（中央上）

**位置・サイズ**

- 中央上に配置
- 幅：約 300px、高さ：約 150px

**表示内容**

- ROM 4 行分（アドレス 0 ～ 3）
- 各行：`[アドレス] 16進数表記 (ニーモニック Im/Addr)`
  ```
  [0] 00 (ADD Im=00)
  [1] 01 (IN)
  [2] 10 (OUT Im=00)
  [3] 11 (JNC Addr=00)
  ```
- 現在実行中の命令をハイライト表示（背景色変更など）

**更新タイミング**

- ROM 読み込み時に全体更新
- PC 更新時にハイライト位置の変更

### 3. 入力/出力パネル（右上）

**位置・サイズ**

- 右上に配置
- 幅：約 200px、高さ：約 150px

**表示内容**

**出力側（LED）**

- A レジスタの 2bit を LED 状で表示
- `LED: [■][■]` または `LED: [□][□]`
- A レジスタ値と常に同期

**入力側**

- 入力値セッター：2bit のチェックボックス or スピナー
- `入力値: [■][■]` （クリック可能）
- IN 命令実行時に A レジスタに転送される値

**更新タイミング**

- LED：A レジスタ更新後に同期
- 入力値：ユーザー操作で変更可能

### 4. 操作ボタンエリア（中央）

**位置・サイズ**

- 全幅に配置
- 高さ：約 60px

**ボタン一覧**

| ボタン         | 動作                                               | 有効状態   |
| -------------- | -------------------------------------------------- | ---------- |
| **▶ 実行**     | 自動実行またはステップ実行を開始                   | 停止中     |
| **⏸ 停止**     | 実行を中断                                         | 実行中のみ |
| **⟲ リセット** | CPU 状態を初期化（A=00, PC=00, C=0, cycles=0）     | 常に有効   |
| **📂 読込**    | ROM ファイルをロード（Tauri のファイルダイアログ） | 常に有効   |
| **💾 保存**    | 現在の ROM 内容を保存                              | 常に有効   |

### 5. 実行ログ表示（下部）

**位置・サイズ**

- 下部に配置
- 全幅、高さ：約 200px
- スクロール可能

**表示内容**

各サイクルごとに以下を記録：

```
[CYCLE n] PC=x, 命令=yy (ニーモニック), A: aa→bb, C: c→c', output=zz
```

詳細情報：

- **CYCLE n**：実行サイクル番号
- **PC=x**：実行前のプログラムカウンタ値
- **命令=yy**：16 進数命令コード
- **ニーモニック**：命令の人間が読める形式
- **A: aa→bb**：A レジスタの変化（実行前 → 実行後）
- **C: c→c'**：キャリーフラグの変化
- **output=zz**：OUT 命令の場合、出力値を記録

**更新タイミング**

- 各サイクル実行後に 1 行追加
- リセット時に履歴をクリア
- 大量行数時は古い行を削除（スクロール負荷軽減）

## UI 状態遷移

```
[停止状態]
    ↓ 実行ボタン押下
[実行中]
    ├→ ステップ完了 → [停止状態]（ステップ実行時）
    ├→ 停止ボタン押下 → [停止状態]
    └→ プログラム終了（PC > 3） → [停止状態]

[任意の状態] + リセット → [停止状態]
```

## レスポンシブ対応

- 基本レイアウトは 1024x768px 以上を想定
- ログ表示エリアは動的にリサイズ可能
- 小画面では各パネルをスタック表示に変更可能
