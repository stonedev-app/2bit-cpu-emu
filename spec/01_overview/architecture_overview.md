# 2bit CPU エミュレーター構成概要

> このエミュレーターは **Tauri** を使ってデスクトップアプリとして実装する。

## 概要

- **React UI**

  - レジスタ表示
  - LED 表示
  - 操作ボタン
  - ログ表示
  - メモリ表示
  - 命令入力

- **CPU エミュレーション (Rust)**

  - ステップ実行
  - 命令デコード
  - レジスタ更新
  - フラグ更新
  - メモリ操作

- **Tauri / Rust**
  - ファイル読み込み (ROM)
  - ファイル書き出し (ROM)
  - 設定保存
